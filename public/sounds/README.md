# Sound files needed

Place the following MP3 files here:

- `wii-music.mp3` - Wii Menu background music
- `hover.mp3` - Wii channel hover sound effect
- `click.mp3` - Wii channel select/click sound effect
- `back.mp3` - Wii back/return sound effect

You can find these sounds on sites like sounds-resource.com or extract them from the original Wii system files.
