## Homelab

I run a self-hosted k3s Kubernetes cluster on bare-metal nodes at home. Full GitOps workflow with ArgoCD, monitoring with Prometheus and Grafana, and a growing list of self-hosted services — Jellyfin, Nextcloud, and more.

Everything is managed as code: manifests in Git, automatic syncs, and pull-request-driven deployments. The cluster runs on multiple nodes with manual storage, IngressRoutes via Traefik, and DNS managed by ExternalDNS with Cloudflare.

It's where I break things on purpose so I don't break them at work.

[View the repo](https://github.com/JordiiBru/homelab)
