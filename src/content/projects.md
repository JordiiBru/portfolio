## Homelab

A self-hosted k3s Kubernetes cluster running on bare-metal nodes at home. Full GitOps workflow with ArgoCD, monitoring with Prometheus and Grafana, and services like Jellyfin, Nextcloud, and more.

[View on GitHub](https://github.com/JordiiBru/homelab)

## Terraform Monorepo

A scalable solution for managing Infrastructure as Code using Terraform. Includes an automated CI/CD pipeline with Terragrunt, TFLint, TFSec, and Infracost for efficient, secure, and cost-effective infrastructure management.

## Kubernetes Community Cluster

A hardware resource sharing system encouraging users to contribute on service hosting. Built with ReactJS, Redis, and ExpressJS.

## Mastermind Boardgame

A retro Java version of the board game Mastermind using a three-layer architecture. Players face a bot using either a traditional or genetic algorithm.
