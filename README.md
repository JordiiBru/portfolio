# Portfolio

Personal portfolio site for [jordibru.cloud](https://jordibru.cloud).

## Stack

- [Astro](https://astro.build/) for static site generation
- Content written in Markdown (`src/content/`)
- Styled with vanilla CSS, no frameworks

## Run locally

```bash
npm install
npm run dev
```

Dev server starts at `http://localhost:4321`.

## Build

```bash
npm run build
```

Output in `dist/`.
